# EdgeIsland Microsoft Store build (v0.3.0)

This additive patch does not replace any existing source, installer or workflow. The Store-specific build substitutes `startup_store.cpp` for `src/startup.c` and retains the rest of the native app. It uses the existing icon, builds with MSVC, and packs with the Windows SDK MakeAppx. Windows 11 x64 only. The MSIX includes only the app, logos, license and privacy policy; the Store owns install and uninstall.

1. Copy all patch folders (including `.github`) into the existing GitHub Desktop repository root, merging folders. Commit and Push. Check both the existing `Windows unsigned build` workflow and the new `Windows Store MSIX` workflow.
2. When the new workflow succeeds, download `EdgeIsland-x64-STORE-MSIX` from Artifacts and extract the ZIP. The `.msix` is the unsigned Store submission package, **not** an ordinary locally installable signed package. Do not upload the ZIP or checksum text to the Packages section. Do not disable security or import unknown certificates.
3. Compare the package identity with the correct MSIX/PWA app in Partner Center: Name `TsangGaming.EdgeIsland`; Publisher `CN=519D7D56-0B43-4900-B8E9-3537D891A7FF`; PublisherDisplayName `TsangGaming`; Store ID `9P2KJXR0W7SP` (the Store ID is not embedded in the manifest).
4. Before public release, test the packaged app on clean Windows 11 x64 using a private Store distribution/flight if available or a separately prepared local test package on a test machine. The unsigned submission package has the exact Store publisher and is not intended for Add-AppxPackage -AllowUnsigned. Avoid installing the existing EXE edition and Store edition together; uninstall the EXE edition before testing the Store edition. No migration of old settings is promised.
5. Test launch from Start, tray exit/reopen, hover/manual gestures, music title/cover/controls, timer, both languages, settings persistence, startup off by default, enabling/disabling in the app and Windows Settings, sign out/in, and uninstall. A task disabled by Windows user or policy cannot be programmatically re-enabled. Verify there are no remaining startup entries after uninstall. Use Windows App Certification Kit if available. A successful build is not a runtime test or Store approval.
6. In Partner Center start a submission; select free pricing, use category Utilities & tools or closest available, upload the actual `.msix`, provide real app screenshots, privacy URL `https://github.com/TsangGaming/EdgeIsland/blob/main/docs/PRIVACY-STORE.md`, and answer the age rating and other questions accurately. Do not publish publicly until packaged runtime tests pass.
7. For `runFullTrust`, explain that the app is a Win32 desktop overlay using window management, system tray, local settings, system stats and media controls with standard-user permissions. `globalMediaControl` is declared for reading and controlling system media sessions; no microphone access or recording. The Microsoft Store signs accepted packages; this does not sign the original EXE distribution.

Local build on Windows with Visual Studio C++ Build Tools and Windows SDK C++/WinRT headers: `python tools/build_msix.py`. Version follows `src/version.h` with a fourth component of zero. Increment the app version before subsequent public updates. No signing credentials or network dependency downloads are required by the build script.
