# Edge Island

Windows 11 x64 的桌面灵动岛。鼠标移入胶囊就展开时钟、媒体控制、计时器和电脑状态，移出整个面板就收起。默认固定在显示器上方正中，也可沿四边摆放。界面默认使用英文，可切换到简体中文。项目以 MIT License 免费开放源代码。

**v0.3.0 是未签名测试版。** 本版加入英文和简体中文界面，以及带进度条的 Windows 安装向导。

## 安装与卸载

1. 在 Windows 11 x64 运行 **EdgeIsland-0.3.0-x64-UNSIGNED-Setup.exe**。欢迎页可选 English 或简体中文，软件会沿用该选择。首次安装默认使用英文。
2. 点击 **Next（下一步）** 查看当前用户的安装位置 **%LOCALAPPDATA%\Programs\EdgeIsland**，再点击 **Install（安装）**。可直接覆盖安装旧版，原有摆放位置、计时器和其他偏好会保留。
3. 安装完成时可勾选 **Open Edge Island（打开 Edge Island）**，再点击 **Finish（完成）**。也可以从开始菜单打开。
4. 从 **设置 → 应用 → 已安装的应用 → Edge Island → 卸载** 清理程序和偏好，也可使用 ZIP 中的独立卸载工具。

如果你的 Windows 安全策略要求受信任的发布者，请使用通过签名验证的后续版本。项目不要求修改系统安全设置。

## 使用

| 想做什么 | 操作 |
| --- | --- |
| 切换界面语言 | 打开 **Settings / 设置 → Language / 语言**，选择 **English** 或 **简体中文**。界面即时切换，重启后保留。 |
| 鼠标移入展开 | 默认使用 **设置 → 展开方式 → 鼠标悬停**。指针碰到胶囊就开始展开，移到面板内的按钮上可以继续操作，离开整个面板就会收起。悬停时键盘焦点留在原来的窗口。 |
| 使用原来的展开方式 | 选择 **设置 → 展开方式 → 点击或拖动**，之后移开鼠标会保持面板打开。单击、向下滚一格或按住胶囊向屏内拉动约 42 个逻辑像素后松手即可展开。向上滚、点右上箭头或按 Esc 收起。 |
| 选择摆放位置 | 展开 **设置**，选 **固定上方正中** 或 **拖动到屏幕边缘**。在边缘模式下沿边拖动胶囊可换位置；按住 Alt 拖胶囊或拖动已展开面板的空白处，可向任意方向移动。松手后吸附到最近的一边。 |
| 移到另一台显示器 | 点 **设置 → 切换显示器**，或在边缘模式下直接拖到另一台显示器。程序记住显示器、边缘和沿边位置。 |
| 看 YouTube 或听音乐 | 在支持 Windows 系统媒体会话的浏览器或播放器开始播放。收起时显示歌名、封面和音柱，播放器暂时没有封面时显示音符图标。新歌开始或恢复播放会自动回到音乐显示。展开 **媒体** 页可看作者和进度，可以播放、暂停、切歌或点击时间轴跳转。按钮随播放器实际能力启用。 |
| 边听歌边看时间 | 媒体胶囊和展开的 **媒体** 页默认显示本地时间。**设置 → 播放音乐时显示时钟** 可关闭它。概览页的时钟始终显示。音柱在播放时起伏，暂停时静止；它反映播放器状态，应用不录音。 |
| 同时播放音乐和倒计时 | 在 **计时** 页选 5、15、25 或 50 分钟，然后开始。支持暂停、继续和重置。收起时按住 Shift 滚轮，或用左右方向键，在活动与时钟之间切换。 |
| 查看电脑数据 | **概览** 显示时间、日期、CPU、RAM、电源状态以及最近一个外部前台应用本次使用时长。**性能** 页还有 CPU 趋势及已用／总物理内存。系统未提供的读数显示为横线。 |
| 查看音量和供电变化 | 更改默认播放设备主音量、静音、插拔供电或电量跌至 20% 时，收起的胶囊会短暂显示状态。 |
| 游戏时隐藏 | 默认启用 **全屏时自动隐藏**，按当前前台窗口与本显示器边界判断。需要时可从托盘打开。 |
| 登录后自动打开 | **设置 → 登录 Windows 时自动启动**，默认关闭。打开后在当前用户下次登录时启动。可随时关闭，卸载时也会清除这项注册。Windows 自身的“启动应用”设置和管理员策略也会影响是否执行。 |
| 键盘与退出 | Tab／Shift+Tab 移动焦点，Enter 或空格操作，方向键切换页面。时间轴获得焦点时，左右键跳转。右键胶囊或托盘图标可打开菜单或退出。 |

首次运行默认以胶囊显示。便携运行主程序也可使用桌面功能。CPU 曲线记录窗口查看期间的样本。计时以结束时间计算，睡眠或重启后会对时。电脑关机时没有声音提醒，重新启动应用时会处理已到期的计时器。

媒体控制来自 Windows 的公开接口。实时导航、Face ID、AirDrop 和其他需要 iOS 或特定应用提供数据的活动没有接入本版本。系统媒体会话未提供封面、时长或切歌权限时，面板会显示对应的空状态。

## 资源开销

应用是原生 Win32 x64 程序，使用 GDI/GDI+ 和系统字体。拖动输入合并到约 15 毫秒一帧，松手的过渡最长约 195 毫秒。过渡复用面板和胶囊画面，文字以原尺寸绘制，结束后释放临时图像。窗口稳定时复用绘制缓冲。音柱每次只重绘五条柱子所在的小区域，标准模式的目标间隔为 33 毫秒，节能模式接电时为 50 毫秒，使用电池时为 80 毫秒。暂停、音柱不可见或 Windows 关闭动画效果时，会停止音柱动画定时器。实际帧率取决于设备、桌面合成和系统调度。

音量、前台应用和媒体变化使用 Windows 事件。媒体提供程序不支持事件时保留低频补查。系统采样使用 `GetSystemTimes`、`GlobalMemoryStatusEx` 和 `GetSystemPowerStatus`，不轮询独显传感器。

节能模式默认开启。CPU／内存仅在相应面板可见时采样，接电约每 2 秒一次，电池约每 4 秒一次。当媒体订阅正常、曲目信息齐全且胶囊收起时，后备媒体检查间隔约为接电 45 秒、电池 60 秒。曲目信息暂缺或需要从多个已暂停的会话中识别新播放时，约每 2.5 秒补查一次。性能历史、媒体封面与前台应用名只在内存中保存。偏好及计时状态变化时才更新注册表。使用者可以在任务管理器查看本机实际占用。

## 从源代码构建

需要 Windows 11 x64、Python 3.9 或更新版本以及 Visual Studio 2022 或更新的 C++ Build Tools。安装 **使用 C++ 的桌面开发** 工作负载，包含 x64 编译工具和 Windows 10/11 SDK。打开源码根目录的 PowerShell，执行以下命令。

```powershell
python tools/build.py
python tools/verify.py --setup build/bin/EdgeIslandSetup.exe --payload-dir build/bin
python tools/bundle.py --setup build/bin/EdgeIslandSetup.exe --uninstaller build/bin/Uninstall.exe --out build/downloads
```

编译脚本会查找已安装的 x64 MSVC。程序、卸载器和安装包在 `build/bin`，带有 `UNSIGNED` 标识的下载文件和 SHA-256 清单在 `build/downloads`。安装包自带所有应用文件。

自动化部署可用 `/quiet /nolaunch` 执行无交互安装，卸载器支持 `/quiet`。退出码 0 表示成功，1 表示操作失败，2 表示用户取消，3 表示已有安装或卸载正在运行。

### 交叉构建这份测试包

本次交付使用 x86_64 Windows TinyCC 交叉编译器，来源为 TinyCC 的提交 `e9e9e7f6236895a32c5e905aada486bab6671e95`。可在 Linux 获取对应的完整源码，使用系统 GCC 构建编译器。以下示例从 Edge Island 源码根目录运行，两个项目放在相邻目录。

```bash
git clone https://github.com/TinyCC/tinycc.git ../tinycc
git -C ../tinycc checkout --detach e9e9e7f6236895a32c5e905aada486bab6671e95
(cd ../tinycc && ./configure --enable-cross && make x86_64-win32-tcc)
python3 tools/build.py --tcc ../tinycc/x86_64-win32-tcc --tcc-root ../tinycc
python3 tools/verify.py --setup build/bin/EdgeIslandSetup.exe --payload-dir build/bin
```

仓库提供所调用的 Windows 系统 DLL 导入名称及资源生成器。最终用户不需要安装编译器、Python 或开发工具。GitHub Actions 使用 MSVC，编译器不同会产生不同的文件哈希。

## 测试与自动打包

`.github/workflows/build.yml` 在 push、pull request 和手动运行时构建未签名版。Windows 作业核对系统 DLL 入口，在 100%、150%、200% 缩放下测试歌名、封面、播放指示与时钟的绘制，并测试安装向导、语言切换、覆盖升级、鼠标进出与焦点、手动下拉和滚轮、计时器、设置持久化、登录启动项和两种卸载方式。通过后提供 `EdgeIsland-x64-UNSIGNED` 工件。Linux 作业验证定位、手势、音柱变化、计时器和 CPU 算法。

本地运行原生 Windows 集成测试请使用没有安装本应用的测试账户。脚本会安装并卸载本产品。如果已有安装、快捷方式或设置，它会停止以保留现有数据。

```powershell
./tests/Windows-Smoke.ps1 -Setup build/bin/EdgeIslandSetup.exe -PayloadDir build/bin
```

需要实际硬件配合的检查包括电池插拔、播放／暂停外部媒体、主音量变化、不同缩放的双显示器和独占全屏游戏。对续航的判断应使用同一台电脑、相同亮度与相同负载进行比较。
